# Do Mercado à Docência

**Programação, Redes e os Desafios na Era da IA** — apresentação para o curso Técnico em Informática Integrado ao Ensino Médio do IFFar, Campus Júlio de Castilhos.

🔗 **Ao vivo:** https://cthaiur.github.io/apresentacao-iff/

Feita em HTML, CSS e JavaScript puros, sem dependências.

## Como navegar

| Tecla | Ação |
|---|---|
| `→` / espaço | avança (slide ou passo) |
| `←` | volta |
| `F` | tela cheia |
| `Home` / `End` | primeiro / último slide |

No celular, deslize para os lados.

## Slides em passos

Para revelar o conteúdo de um slide aos poucos, adicione `data-steps="N"` na `<section>` e `data-step="1"`, `data-step="2"`… nos elementos que devem aparecer a cada `→`.
